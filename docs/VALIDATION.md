# 검증 기록

검증일: 2026-10-15. 제공된 C 소스는 변경하지 않았습니다. 최종 버전에 Makefile, 재현 가능한 통합 테스트 스크립트, GitHub Actions 워크플로를 추가했습니다.

## 환경

- WSL Ubuntu 24.04
- GCC, C11, `-O2 -Wall -Wextra`
- OpenSSL 3.0.13
- localhost TCP 10101

## 실제 수행 결과

| 항목 | 결과 |
| --- | --- |
| 최종 서버·클라이언트 빌드 (`make -C src`) | 성공, 경고 출력 없음 |
| 과거 단계 01~04 서버·클라이언트 컴파일 | 8개 모두 성공 (02 클라이언트만 미사용 인자 경고 2건) |
| 64 KiB를 넘는 바이너리 파일 업로드·다운로드 | 성공, 262,154바이트 원본과 수신 파일의 바이트 전체 일치 |
| 빈 파일 업로드·다운로드 | 성공, 0바이트 유지 |
| 서버 파일 목록 AES-GCM 인증 | 성공 |
| 미등록 클라이언트 개인키 사용 | 접속 거부, 클라이언트 종료 코드 1 |
| 잘못된 서버 공개키 사용 | 접속 거부, 클라이언트 종료 코드 1 |
| 두 클라이언트 병렬 실행 후 목록 조회 | 두 호출 모두 성공 |
| 정상 전송 후 임시 파일 | 서버에 잔여 `.tmp` 없음 |

## 재현

```bash
make -C src
python3 scripts/smoke_test.py
```

Python 3와 OpenSSL CLI가 필요합니다. 스크립트는 OS 임시 폴더에 테스트 키·파일을 만들고 종료할 때 지웁니다. TCP 10101 포트를 이미 사용 중이면 실행하지 않습니다. 실제 키나 실제 전송 파일은 사용하지 않습니다.

같은 빌드와 테스트는 push마다 [GitHub Actions](../.github/workflows/ci.yml)에서 실행됩니다.

## 발표 자료

`docs/presentations/`의 PDF 4개는 원본 PPTX를 PDF로 변환한 것입니다. 변환하면서 표지의 팀원 학번만 지웠고, 다른 슬라이드 내용은 바꾸지 않았습니다. PPTX에 들어 있던 시연 영상과 임베디드 폰트는 PDF에 포함되지 않습니다.

## 범위

과거 단계는 컴파일만 확인했고 실행 검증은 하지 않았습니다. 실제 Raspberry Pi·Termux 재시연, 장시간 부하 시험, 네트워크 변조 주입, 전체 보안 감사도 수행하지 않았습니다. 정상 동작과 잘못된 키 거부를 확인한 테스트는 프로토콜 전반의 보안성을 증명하지 않습니다.
